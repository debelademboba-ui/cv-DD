# Debele Demboba CV

## Run in VS Code

1. Open this folder in VS Code.
2. Make sure the structure is:

cv_debele/
├── index.html
├── style.css
└── assets/
    └── profile.jpg

3. Open `index.html` in your browser.

### Recommended
Install the VS Code extension **Live Server**, then:
- Right-click `index.html`
- Select **Open with Live Server**

## Change your photo

Replace:
`assets/profile.jpg`

with your own photo, keeping the same filename.

## Export to PDF

Open the CV in Chrome:
`Ctrl + P` → Destination: **Save as PDF** → Paper size: **A4** → Save.
